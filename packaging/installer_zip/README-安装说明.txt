AI 社交秘书（Windows 11）安装说明
==================================

一、这是什么？
--------------
AI 社交秘书是一个只读的社交消息整理助手：把 QQ 与 QQ 邮箱里值得你花注意力处理的消息，
整理成今日摘要、重要/普通/仅供了解三级分类、待办事项与可编辑的回复草稿。

它**不会**发送 QQ 消息、不会发送邮件、不会修改联系人、不会删除远端消息。

二、安装步骤（不需要管理员权限）
--------------------------------
1. 把本安装包 ZIP 解压到一个普通文件夹（例如桌面或下载文件夹，不要在压缩包里直接运行）。
2. 双击 `安装.cmd`。
3. 按提示完成安装（默认安装到当前用户目录，不需要管理员权限）。
4. 安装完成后可从「开始菜单」或桌面快捷方式启动「AI 社交秘书」。

本安装包包含：
- `安装.cmd` / `安装.ps1`：安装入口（PowerShell 脚本，内容可打开查看，完全透明）；
- `卸载.cmd` / `卸载.ps1`：卸载入口；
- `app\`：程序本体（AI 社交秘书 onedir）；
- 本说明文件。

三、安装位置
------------
- 程序目录：%LOCALAPPDATA%\Programs\SocialSecretary（安装时可自定义）
- 用户数据：%LOCALAPPDATA%\SocialSecretary（消息、摘要、待办、设置、日志）
  程序目录与用户数据分开存放，**卸载时默认保留用户数据**。

四、卸载
--------
方式一：Windows「设置 → 应用 → 已安装的应用」中找到「AI 社交秘书」→ 卸载。
方式二：双击本安装包里的 `卸载.cmd`（如果程序已被删除，可用它清理残留）。

卸载时会询问是否同时删除本地数据：默认「否」（保留数据）。选择「是」会删除
%LOCALAPPDATA%\SocialSecretary 下的消息、摘要与设置，**不可恢复**，请谨慎。

五、常见问题
------------
1. 双击 `安装.cmd` 没反应 / 提示无法运行脚本？
   右键 `安装.cmd` →「以 PowerShell 运行」，或在文件夹空白处 Shift+右键 →
   「在此处打开 PowerShell 窗口」，执行：
       powershell -NoProfile -ExecutionPolicy Bypass -File .\安装.ps1
2. 想安装到其它目录？
   双击 `安装.cmd` 后终端里会显示安装位置；高级用户可执行：
       powershell -NoProfile -ExecutionPolicy Bypass -File .\安装.ps1 -InstallDir "D:\Apps\SocialSecretary"
3. 安装失败怎么办？
   安装脚本会自动回滚（删除本次已复制的文件和新建的快捷方式/登记项），
   不会留下半成品；失败原因会显示在窗口里，可截图反馈。
4. 会收集或上传我的数据吗？
   不会。程序默认完全本地运行；只有你在设置里逐项明确同意后，外部 AI 功能才会发送
   当前单条消息。邮箱授权码只保存在 Windows 凭据管理器。

六、安全说明
------------
- 安装/卸载脚本只写当前用户的程序目录、开始菜单/桌面快捷方式，以及
  HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\SocialSecretary 卸载登记项；
- 不请求管理员权限、不修改系统设置、不写任何消息内容到注册表或日志；
- 所有脚本都是纯文本，可用记事本打开审阅。
