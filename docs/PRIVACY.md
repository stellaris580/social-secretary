# 隐私与功能限制

> 本文件是面向用户和贡献者的公开说明，不是法律意见。完整产品验收记录不随仓库公开，以免包含个人测试数据。

## 只读边界

- 本程序不发送 QQ 消息，不发送邮件；
- 不撤回、删除或修改 QQ/邮箱服务器上的消息；
- 不读取 QQ 本地消息数据库；
- 不抓取账号密码，不使用 QQ 非官方协议；
- 不修改 QQ 客户端文件。

程序在读取 QQ 时会短暂占用 QQ 前台窗口；打开会话可能改变 QQ 未读状态。首次使用必须由用户本人完成邮箱授权和 QQ 会话选择。

## 本地数据

- 消息、摘要、待办、草稿保存在本机 SQLite（默认 `%LOCALAPPDATA%\SocialSecretary`）；
- 邮箱授权码、外部 AI API Key 只保存在 Windows 凭据管理器；
- 卸载默认保留本地数据，只有用户明确选择删除数据时才删除；
- 测试/证据文件不进入 Release 包，公开仓库只包含源代码、合成测试数据和文档。

## 外部 AI

外部 AI 默认关闭。启用前用户需要：

1. 自备兼容 API Key；
2. 在设置中明确同意数据处理；
3. 接受可能产生的费用。

启用后只上传当前操作所需的最少消息内容，不上传邮箱授权码或凭据。外部模型输出不保证正确，失败时回退本地规则。

## QQ 实验性限制

QQ 聊天读取仍为实验性功能：

- 不能保证完整读取全部历史消息；
- 可能漏读；
- 同一条消息可能重复保存；
- Windows UI Automation 没有已验证的永久消息 ID；
- 无法可靠确认每条入库记录都是独立的新消息；
- 图片、文件、表情、群聊格式可能不完整；
- QQ 最小化、托盘或遮挡时可能读取失败；
- 切换聊天可能改变已读状态；
- 重要通知请以原始 QQ 客户端为准。

**A1 消息完整性预检存在 FAIL；QQ 精确去重尚未解决。不要把本程序作为重要 QQ 消息的唯一依据。**

## 权限

- 不需要管理员权限；
- 不需要安装 Python（使用 Release 包）；
- 不申请管理员常驻、无障碍提权或绕过系统安全边界。
