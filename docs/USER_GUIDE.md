# 新手指南（公开版）

## 安装

1. 下载 Release 中的 `SocialSecretary-v0.2.5-beta-installer.zip`（安装版）或 `SocialSecretary-v0.2.5-beta-portable.zip`（便携版），在资源管理器里右键「全部解压缩」；
2. 双击解压目录中的 `安装.cmd`；
3. 不需要管理员权限，不需要安装 Python；
4. 也可下载便携版，解压后直接双击 `SocialSecretary.exe`。

## 首次配置

### QQ 邮箱

1. 左侧「收件箱」→「连接 QQ 邮箱」；
2. 输入邮箱地址；
3. 填 **授权码**（不是 QQ 密码）。在 `mail.qq.com` 设置中开启 IMAP 并按提示生成；
4. 同意只读读取后同步。

### QQ 聊天（实验性）

1. 点「管理授权会话」；
2. 点按钮读取当前 QQ 可见会话名称（不读内容）；
3. 只勾选你自己的测试会话或明确允许读取的会话；
4. 阅读风险提示后保存。

首次开启 QQ 前请阅读完整限制：QQ 读取可能漏读、重复保存、无法确认独立新消息；QQ 隐藏/托盘时可能失败。重要信息以原始 QQ 为准。

## 日常使用

1. 打开程序；
2. 点「一键整理所有消息」；
3. 查看今日摘要、待办和消息中心；
4. 在消息详情生成回复草稿，自己复制到 QQ/邮箱手动发送；
5. 「设置与隐私」可暂停采集、撤销授权、删除本地数据。

## 卸载

开始菜单/设置 → 应用 →「AI 社交秘书」→ 卸载。默认保留本地数据；只有明确选择删除数据时才删除。

## 常见问题

- **QQ 读取失败**：先打开 QQ 完整主面板，保持可见，再重试；
- **邮箱失败**：检查 IMAP 是否开启、授权码是否过期；
- **部分完成**：按首页黄色提示处理，不要当成全部成功；
- **重要消息**：始终回原始 QQ/邮箱核对。
