# 开源发布安全审计摘要

本文件说明本仓库公开范围与审计结论。完整开发期验收证据包含个人测试数据，**不随公开仓库发布**。

## 公开范围

公开的是经过选择和清洗的：

- `src/social_secretary/`：Tkinter 主程序源码（不含开发期 acceptance 诊断模块和实验性 Qt UI）；
- `tests/`：离线/合成数据测试（不含真实 QQ、真实邮箱、真实凭据）；
- `tools/`：运行测试所需的最小离线工具（mock IMAP、导入/QQ 探针等，已清理本机路径）；
- `packaging/`：构建 Windows 包所需脚本、资源与第三方 NOTICE；
- `docs/`：重新编写的用户/隐私/架构/开发文档；
- `config/qq_ui_profile.json`：QQ UIA 选择器配置，无账号数据。

## 未公开内容

- `evidence/`：真实测试证据、截图、日志；
- `.tmp/`、`dist/`、构建缓存、备份、虚拟环境；
- 真实 SQLite 数据库、邮箱/聊天缓存；
- Windows 凭据、邮箱授权码、API Key；
- 私有测试会话名称、真实账号/邮箱/姓名；
- 开发仓库原始 Git 历史；
- 第三方参考仓库源代码（仅在 README/NOTICE 中注明设计参考）。

## 审计结果

- 公开导出目录：已二次扫描，未发现真实账号、邮箱、姓名、本机用户路径、数据库或真实 API Key；
- 测试中出现的 `sk-` 值均为明显测试占位符，不构成生产凭据；
- 原始开发仓库历史包含真实测试标识和旧证据路径，因此**没有推送原始历史**；公开仓库使用新的初始提交；
- 未发现需要轮换的生产 API Key（历史中的 key 形状均为测试占位符）；
- 第三方组件许可证见 `THIRD_PARTY_NOTICES.md`；本项目原创代码采用 MIT；
- 公开仓库不包含腾讯/QQ 客户端代码或第三方 QQ 自动化参考仓库源码。

## 已知限制

QQ 聊天读取为实验性：可能漏读、重复保存，Windows UIA 没有已验证的永久消息 ID；A1 完整性预检存在 FAIL；精确去重尚未解决。重要信息以原始 QQ 为准。
